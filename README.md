# Cursor AI Code Refactoring

A Python practical project demonstrating how Cursor AI can help improve code readability, apply coding standards, and validate program output.

## Project Overview

This project uses Cursor AI Agents to analyze and refactor a Python student-marks program. It explores AI-assisted code improvements while checking whether the program's output remains consistent with the original output.

## Features

- **Code Refactoring:** Improve code readability using descriptive names.
- **Coding Standards:** Apply Python guidelines through Cursor rules.
- **Output Validation:** Compare program output with the original output file.
- **AI-Assisted Development:** Use Cursor AI Agents to suggest code improvements.
- **Reusable Functions:** Organize calculations into functions.

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in Cursor or another code editor.
4. Run the Python program:

   ```bash
   python messi_py.py
   ```

5. Compare the output with `output.txt`.
